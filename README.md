# Atmosphera — Weather Intelligence

A modern weather web app built with HTML, CSS, and JavaScript.

## Features
- Real-time weather data using Open-Meteo API
- 24-hour forecast
- 7-day forecast
- UV index, wind, humidity, pressure
- Geolocation support
- Clean, responsive UI
